# 0. Запрещено
- ❌ Заметки без названия
    
- ❌ Папки «разное», «всякое», «черновики» и т.п
    
- ❌ Дублирующие заметки
    
- ❌ Удаление (если хотите что-то удалить, перемещайте это в [[Archive]])
# 1. Общие принципы

1. **Одна заметка — одна мысль.**  
    Если заметка длиннее экрана — делим на две.
    
2. **Название говорит само за себя.**  
    Не `Заметка123`, а `Movement`.
    
3. **Без пробелов в названиях.**  
    Используй `_` или `-`. Пробелы убивают поиск. 
    
4. При изменении или внесения данных в заметки, подписывайте кто изменил/добавил
	 Используйте следующий шаблон:
	
---

author: bogich
date: 2026-04-03
# Заголовок
## Кратко
Коротко о чем заметка
## Подробности
- Факт 1
- Факт 2
- Факт N

---
# 2. Правила именования веток в Git

### Формат

тип/описание-кейс (дефисы, маленькие буквы)
### Типы веток

| Префикс   | Назначение                                | Пример                |
| --------- | ----------------------------------------- | --------------------- |
| `feat/`   | Новая функция (фича)                      | `feat/door-opening`   |
| `fix/`    | Исправление бага                          | `fix/save-crash`      |
| `hotfix/` | Срочный баг в основной ветке              | `hotfix/prod-crash`   |
| `docs/`   | Обновление документации                   | `docs/readme-update`  |
| `chore/`  | Вспомогательные задачи (не влияют на код) | `chore/unity-upgrade` |
| `Levels/` | Изменение уровня                          | `Levels/level-01`     |
### Примеры

✅ `feat/inventory-ui`  
✅ `fix/door-clipping`  
❌ `Feat/Inventory UI` (большая буква, пробел)  
❌ `fix/save_crash` (подчёркивание)
